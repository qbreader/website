GET qbreader.org/api/leaderboard

Rank every user by the number of questions they have heard. Results are recomputed at most once every five minutes.

This endpoint is not open. It returns every user's username alongside their play stats, so it requires a key. Contact a maintainer for access; unauthorized requests receive 401.

Parameters
  • key: string Required
    The access key you were given. Requests with a missing or incorrect key receive 401.
  • limit: number Optional
    The maximum number of users to return. Defaults to 50, and is clamped to the range 1–500.
  • minQuestions: number Optional
    Exclude users who have heard fewer than this many questions. Defaults to 0. Applied before limit.

Returns
A JSON object with the following properties:
  • leaderboard: Object[]

    An array of objects, sorted from most to least questions heard. Users who have been deleted are omitted. 

    {
    _id: string                     // the user's id
    username: string
    tossupCount: number             // tossups heard
    bonusCount: number              // bonuses heard
    total: number                   // tossupCount + bonusCount
    numCorrect: number              // tossups answered correctly
    powers: number                  // tossups buzzed for 15 or more
    tens: number                    // tossups buzzed for exactly 10
    negs: number                    // tossups buzzed for a negative value
    tossupPoints: number
    bonusPoints: number
    points: number                  // tossupPoints + bonusPoints
    pptu: number                    // points per tossup heard
    ppb: number                     // points per bonus heard
    accuracy: number                // numCorrect / tossupCount, from 0 to 1
    averageCorrectCelerity: number  // from 0 to 1; higher means an earlier buzz
}
  • count: number
    The number of users in leaderboard.
  • generatedAt: string
    An ISO 8601 timestamp for when these rankings were computed.

Errors
  • 401
    The key parameter is missing or incorrect.
  • 503
    The rankings could not be computed. Returns a JSON object containing an error string.
