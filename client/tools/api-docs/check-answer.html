GET qbreader.org/api/check-answer

Judge an answer to be correct, incorrect, or prompt. Directed prompts are supported.

Parameters
  • answerline: string required
    The answerline of the question. Preferably including the HTML tags <b> and <u>, if they are present.
  • givenAnswer: string required
    The answer to check.

Returns
A JSON object with the following properties:
  • directive: "accept" | "reject" | "prompt"
  • directedPrompt: string | null
